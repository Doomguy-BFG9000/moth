# Difference of Squares

For the first ten whole numbers, the square of their sum is (1 + 2 + ... + 10)² = 55² = 3025, and the sum of
their squares is 1² + 2² + ... + 10² = 385. The difference is 3025 - 385 = 2640.

Write `square_of_sum`, `sum_of_squares` and `difference`, each for the first n whole numbers.
