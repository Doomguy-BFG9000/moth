# Word Count

Count how many times each word comes in some text, as a dictionary from each word, in small letters, to its
count. Words are made of letters and digits, and can have an apostrophe inside them (`don't`); anything else
(spaces, punctuation, new lines) is between words. So `"That's the password: 'PASSWORD 123'!"` has
`that's` 1, `the` 1, `password` 2 and `123` 1.

Write `count_words`.
