# Raindrops

Turn a number into the sound of rain:

- if it can be divided by 3, add `Pling`;
- if it can be divided by 5, add `Plang`;
- if it can be divided by 7, add `Plong`;
- if it can be divided by none of them, it's the number itself, as text.

So 15 is `PlingPlang`, 105 is `PlingPlangPlong`, and 34 is `34`. Write `convert`.
